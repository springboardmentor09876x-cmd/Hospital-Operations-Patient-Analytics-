# MedTrack_DV - Final Dashboard Report

## Hospital Operations & Patient Analytics Dashboard

---

## 1. Project Overview

MedTrack_DV is a hospital operations and patient analytics dashboard project designed to transform healthcare operational data into actionable insights.

The project focuses on:

- Hospital admissions and patient flow
- Hospital performance monitoring
- Department-level performance analysis
- Patient readmission analysis
- Bed and resource utilization
- Staff allocation
- Equipment utilization
- Capacity planning

The final dashboard suite consists of four interconnected dashboards:

1. Hospital Overview
2. Patient Flow
3. Department Analytics
4. Resource Utilization

The dashboards provide an interactive environment for monitoring hospital operations and supporting data-driven operational decision-making.

---

## 2. Project Objectives

The main objectives of the project are:

- Integrate hospital and patient datasets into a unified analytical dataset.
- Clean and standardize healthcare operational data.
- Engineer hospital performance KPIs.
- Analyze hospital admissions and patient flow.
- Compare department-level performance.
- Monitor hospital resource utilization.
- Provide capacity and resource availability insights.
- Develop interactive dashboards with filters and navigation.
- Validate dashboard metrics against the underlying dataset.
- Deliver a complete and documented dashboard solution.

---

## 3. Dataset Overview

The project dataset contains approximately 10,000 patient records and includes hospital, patient, admission, department, resource, equipment, and financial information.

### Major Dataset Fields

The dataset includes fields such as:

- Patient ID
- Patient Name
- Gender
- Age
- Blood Type
- Hospital Name
- Doctor
- Department
- Admission Date
- Discharge Date
- Length of Stay
- Admission Type
- Patient Status
- Readmission
- Transfer Rate
- Equipment Status
- Equipment Type
- Equipment ID
- Beds Available
- Bed Occupied
- ICU Beds
- Staff
- Billing Amount
- Department Efficiency
- Revenue
- Capacity
- Resource Utilization
- Equipment Usage

The final analytical dataset was prepared through data collection, integration, cleaning, transformation, and KPI engineering.

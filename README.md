🏥 MedTrack_DV – Hospital Operations & Patient Analytics Dashboard

📌 Overview

MedTrack_DV is a healthcare data analytics project designed to analyze hospital operations, patient admissions, department performance, and resource utilization.

The project uses Python for data cleaning and KPI engineering and Tableau for interactive data visualization. The processed healthcare data is transformed into meaningful insights through a unified dashboard suite.

📊 Dashboards

The project includes four interconnected Tableau dashboards:

* Hospital Overview – Hospital performance, admissions, occupancy, and readmission insights.

* Patient Flow – Admission, discharge, patient movement, and length-of-stay analysis.

* Department Analytics– Department-wise patient volume, efficiency, and readmission analysis.

* Resource Utilization– Bed, staff, equipment, and resource utilization analysis.

🛠️ Tech Stack

* Python

* Pandas & NumPy

* Jupyter Notebook

* Tableau Desktop / Tableau Public

* Excel / CSV

* Git & GitHub

🎯 Key Features

* Hospital performance KPI analysis
* Patient admission and flow analysis
* Department-level performance comparison
* Resource and bed utilization analysis
* Interactive Tableau filters and parameters
* Dashboard navigation and actions
* Data cleaning and transformation pipeline

🚀 Outcome

The project provides an interactive, data-driven view of hospital operations, helping users understand patient trends, department performance, and healthcare resource utilization for better operational decision-making.
